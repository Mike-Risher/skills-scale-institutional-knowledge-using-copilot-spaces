# OctoAcme Project Management Docs

This folder contains OctoAcme's project management guidance. OctoAcme manages work through a lifecycle of initiation, planning, execution, release, and retrospective improvement. Teams define outcomes and stakeholders up front, break approved work into prioritized increments with clear acceptance criteria, track delivery and risks through regular team rhythms and project boards, and use testing, deployment checks, and rollback plans to support safe releases. Retrospectives turn delivery and incident learnings into owned, trackable improvements.
